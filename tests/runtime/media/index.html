Pruebas multimedia

Ejecutar en la APK de Archium con los cambios multimedia. Se reproducen patrones y tonos sintéticos; no se utiliza contenido personal.

El resultado automático exige avance del tiempo y fotogramas de vídeo. Sonido audible, pantalla completa, PiP y aceleración requieren comprobación adicional en el dispositivo.

Después de las pruebas, usa los controles del vídeo para comprobar el tono, pantalla completa y las opciones disponibles.

Pendiente de ejecución. Un navegador distinto no valida Archium.
