# Render de Archium: Arc para Mac y contraseñas locales

Archivo: `archium-arc-mac-concept-v1.png`.
Generado el 2026-10-06 mediante imagegen como propuesta visual solicitada por el
usuario. No es captura de una APK ni prueba de funciones implementadas.

Representa la sidebar con navegación/dirección, Favorites, fijados y pestañas
abiertas; marco coral y contenido redondeado; controles locales inferiores y
gestor de contraseñas con importar/exportar CSV. Las entradas son ficticias.

Sirve para revisión del objetivo visual. Las referencias oficiales Mac y las
capturas reales de pruebas siguen siendo necesarias para validar equivalencia.
El ancho ilustrado y el color coral no sustituyen la adaptación a ventana ni el
color personalizable definido en la especificación.

La presentación del gestor como popover en el render ilustra su información y
acciones; la implementación planificada usa una pantalla nativa de ajustes.
La posición/formato final se revisará junto al resto de la UI para evitar prometer
una interfaz que no se vaya a construir.
