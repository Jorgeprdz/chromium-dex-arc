## Root causes and changes

- The bounds callback looked up LocationBar inside its original holder every
  time. Once Fusebox reparented the editor, closing could not clear the native
  command bridge. endInput then delegated to a command already CLOSED and
  did not suspend native input/scrim. Capture the actual LocationBar reference
  once and keep using it through the complete close transaction.
- While a command owns the holder, native autocomplete continues running but
  does not perform its second popover reparent. End an existing Ctrl+L input
  session before transferring its holder into a new command.
- Native desktop session activation replaces empty text with the current
  page URL. After new-command activation, clear initial/user text and the
  prior preview URL. Resumed drafts and ordinary Ctrl+L retain native behavior.
- During commands, LocationBarTablet uses the panel header dimensions and a
  transparent background. Snapshot/restore child layout parameters and bottom
  padding on entry/exit; restore normal native presentation afterwards.
- Native suggestions already have the anchor/Side UI horizontal origin.
  Subtract that origin once, including RTL's right-aligned base. Vertical
  margins continue to use content coordinates.
- Stable panel geometry, rail bounds and collection budgets no longer request
  another layout. Actual changes still resize and update the shell.
