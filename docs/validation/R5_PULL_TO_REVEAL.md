# Phone pull to reveal + native refresh

Approved flow: at the top of a web page, a short downward drag exposes upper web controls and leaves a temporary colored gap. A longer drag continues into Chromium's existing pull-to-refresh. Based on4a622d52b46fd6672005abc26696885990631ddb; this feature is separate from the already successful/installed run40099588583. One incremental build was authorized after checking the refined64dp/120dp specification. Dispatch remains pending final local gates.

The existing native SwipeRefreshHandler gates activation (touchscreen, top overscroll, CSS overscroll policy, refresh enabled). Phone-only opt-in consumes the first64dp of finger drag, up to64dp visual reveal. Under24dp raw cancels; a deliberate short pull settles to64dp and stays after release. The second stage maps the64–120dp finger range into the pinned widget's unchanged64dp native trigger/.5 drag rate. Only excess deltas, including negative rewind, reach the native widget. Each new gesture has a fresh drag budget even when the gap is already revealed, preventing repeated short gestures from accidentally refreshing. That widget retains its threshold, indicator, activation check, accessibility, haptics and reload. A short reveal never attaches the full-screen refresh child.

ArcPhonePullReveal translates the existing compositor/content/input hierarchy together. No setSize, viewport, zoom, UA, DOM or snapshots. The gap is a bounded colored drawing behind the page and controls, not above them. Its decorative view is disabled/nonclickable/nonfocusable and excluded from accessibility. Chromium's native page theme color supplies the fill; native Archium light/dark/incognito surface is the fallback. No claim that metadata always matches the exact CSS header pixel color.

Pull activation compacts the approved controls, retaining the Archium button and the selected status-bar behavior. Expanding controls, normal scroll, focus, navigation, tab changes, pause, fullscreen, resize and Desktop transition restore the owned offset. Native renderer cancellation also resets the effect. Existing dimensions/materials of pills and Desktop remain unchanged. Web pages that disable native overscroll retain that choice; this is not a global touch interceptor overriding site or OS gestures.
